# SP2 (M0+M1): tvOS Scaffold + Playback Spike Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the native tvOS app skeleton (`clients/tvos/`) that builds in the tvOS simulator, then prove the go/no-go thesis: **AVPlayer natively plays the Apple-grade HLS the SP1 server now emits** — direct, remux, and (where the simulator allows) HEVC, with the subtitle picker populated from in-manifest renditions.

**Architecture:** A Swift 6 tvOS app generated by XcodeGen (`project.yml` in git, `.xcodeproj` gitignored), deployment target tvOS 17, built with the tvOS 26 SDK. An `OrbixKit` module holds the typed API client (`actor OrbixClient`, async URLSession + Codable DTOs), a Keychain token store, and a downsampling disk-cached image loader. The app layer for M0 is a reachability check; for M1 a bare "list → play" spike driving stock `AVPlayerViewController` through the `POST /api/playback/info` contract with the tvOS capability profile. This lives OUTSIDE the pnpm workspace (`clients/tvos/` is not matched by `apps/*`/`packages/*`), so pnpm/turbo/eslint ignore it entirely.

**Tech Stack:** Swift 6.x, SwiftUI, AVKit (`AVPlayerViewController`), Foundation URLSession, Security (Keychain), XcodeGen 2.45.4, `xcodebuild` against the "Apple TV 4K (3rd generation)" simulator (tvOS 26.5 runtime installed).

**Spec:** `docs/superpowers/specs/2026-07-03-tv-app-and-client-server-contract-design.md` §5. Consumes the SP1 server contract (device pairing + bearer tokens, `POST /api/playback/info`, Apple-grade HLS with `subtitleDelivery` capability), all merged on this branch (HEAD 1473004).

## Global Constraints

- All tvOS code lives under `clients/tvos/`; **never** add it to `pnpm-workspace.yaml` or touch `apps/*`/`packages/*` from here. The server is consumed only over HTTP.
- **Deployment target tvOS 17.0**, built with the tvOS 26 SDK. Do not use tvOS-26-only API without a fallback (nothing in M0/M1 needs it).
- The app **only ever calls a user-configured absolute base URL** + relative `/api/...` paths (mirror the web client's discipline). No hardcoded server origin in committed code — the dev base URL is injected at runtime (launch arg / env / on-screen field), never baked in.
- **ATS for LAN plain-HTTP**: Info.plist ships `NSAppTransportSecurity` with `NSAllowsLocalNetworking=true` + `NSAllowsArbitraryLoads=true`, and declares `NSLocalNetworkUsageDescription` (no prompt on tvOS, declared for hygiene).
- **AVPlayer auth**: AVPlayer/AVURLAsset send no `Authorization` header or cookies on segment fetches. Playback URLs MUST carry the device token as `?token=` — and the SP1 server already embeds `&token=` into `streamUrl` for bearer-authenticated `/playback/info` calls, and echoes it into every playlist URI. The client uses `streamUrl` verbatim; it must NOT strip or rebuild it.
- **tvOS capability profile** (the exact object sent to `/playback/info`): `{ containers: ["mp4"], videoCodecs: ["h264","hevc"], audioCodecs: ["aac","ac3","eac3","flac"], maxAudioChannels: 6, subtitleDelivery: "hls" }`. `subtitleDelivery: "hls"` is what makes the server emit `EXT-X-MEDIA` subtitle renditions so the native picker is populated.
- Swift 6 language mode; concurrency-safe (`Sendable` DTOs, `actor` for mutable auth/session state). Xcode 26 defaults new targets to MainActor-by-default — keep `OrbixClient` an explicit `actor` for off-main use.
- Build verification is `xcodebuild ... -destination 'platform=tvOS Simulator,name=Apple TV 4K (3rd generation)' build` returning `** BUILD SUCCEEDED **`. Commit after every task.
- `clients/tvos/.gitignore`: `*.xcodeproj/`, `.build/`, `DerivedData/`, `*.xcworkspace/xcuserdata/`.

### Task 2: OrbixKit — DTOs, OrbixClient, Keychain, image loader

**Files:**
- Create: `clients/tvos/Sources/OrbixKit/DTOs.swift`
- Create: `clients/tvos/Sources/OrbixKit/OrbixClient.swift`
- Create: `clients/tvos/Sources/OrbixKit/TokenStore.swift`
- Create: `clients/tvos/Sources/OrbixKit/ImageLoader.swift`
- Modify: `clients/tvos/Sources/OrbixKit/OrbixKit.swift` (keep the version stub)
- Create: `clients/tvos/Tests/OrbixKitTests/DTOTests.swift`
- Modify: `clients/tvos/project.yml` (add a test target)

**Interfaces:**
- `Sendable` Codable DTOs matching the SP1 API exactly:
  - `struct Capabilities: Codable, Sendable` = `{ containers: [String], videoCodecs: [String], audioCodecs: [String], maxAudioChannels: Int, hlsMultichannelAacBroken: Bool?, subtitleDelivery: String? }` with a static `.appleTV` = the tvOS profile from Global Constraints.
  - `struct PlaybackInfoRequest: Codable, Sendable` = `{ fileId: String, capabilities: Capabilities, audioTrackIndex: Int? }`.
  - `struct AudioTrack: Codable, Sendable` = `{ index: Int, codec: String?, channels: Int?, language: String?, selected: Bool }`.
  - `struct SubtitleTrack: Codable, Sendable` = `{ index: Int, codec: String?, language: String?, available: Bool, reason: String? }`.
  - `struct PlaybackInfo: Codable, Sendable` = `{ playSessionId: String, mode: String, streamUrl: String, container: String?, videoCodec: String?, audioTracks: [AudioTrack], subtitleTracks: [SubtitleTrack] }`.
  - `struct MediaCard: Codable, Sendable` = `{ id: String, title: String, year: Int?, posterPath: String? }` (decodes the common fields of home-row/catalog items; extra fields ignored).
  - `struct HomeRow: Codable, Sendable` = `{ key: String, title: String, items: [MediaCard] }`; `struct HomeRows: Codable, Sendable` = `{ rows: [HomeRow] }`.
  - `struct PairInitiateResponse: Codable, Sendable` = `{ code: String, pollToken: String, expiresInSec: Int }`.
  - `enum PairPollResponse` decoding `{ status: "pending" }` vs `{ status: "approved", deviceToken, deviceId }`.
  - `struct Profile: Codable, Sendable` = `{ id: String, name: String, avatar: String?, kind: String?, maturityCap: Int?, language: String? }`.
- `actor OrbixClient`: `init(baseURL: URL, token: String?)`; `func setToken(_:)`; async methods `serverReachable() -> Bool` (GET `/health`, 200), `pairInitiate(name:) -> PairInitiateResponse`, `pairPoll(pollToken:) -> PairPollResponse`, `profiles() -> [Profile]`, `selectProfile(id:) async throws`, `homeRows() -> HomeRows`, `playbackInfo(fileId:capabilities:audioTrackIndex:) -> PlaybackInfo`. All requests attach `Authorization: Bearer <token>` when set; JSON via `JSONEncoder`/`JSONDecoder`. Throws `OrbixError` (`.http(Int)`, `.decoding(Error)`, `.transport(Error)`).
- `actor TokenStore`: Keychain-backed (`kSecClassGenericPassword`, `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`); `save(token:)`, `load() -> String?`, `clear()`. Service `dev.orbix.tvos`, account `device-token`.
- `actor ImageLoader`: `image(for url: URL) async -> Data?` with an in-memory + disk (`caches`) cache; the app builds absolute image URLs as `baseURL/api/images/<posterPath>` (public, no auth).

- [ ] **Step 2: Write the failing DTO test**

`clients/tvos/Tests/OrbixKitTests/DTOTests.swift` — decode a captured `/playback/info` JSON payload (remux mode, one audio track, one available + one image-based subtitle track) and assert fields; decode a `pair/poll` approved payload; assert `Capabilities.appleTV` has `subtitleDelivery == "hls"` and includes `hevc`. Use `XCTest`. Example core assertion:

```swift
import XCTest
@testable import OrbixKit

final class DTOTests: XCTestCase {
    func testDecodePlaybackInfoRemux() throws {
        let json = """
        {"playSessionId":"s1","mode":"remux","streamUrl":"/api/play/f1/master.m3u8?playSessionId=s1&token=orb_x",
         "container":"matroska,webm","videoCodec":"h264",
         "audioTracks":[{"index":0,"codec":"ac3","channels":6,"language":"ru","selected":true}],
         "subtitleTracks":[{"index":2,"codec":"subrip","language":"en","available":true},
                            {"index":3,"codec":"hdmv_pgs_subtitle","language":"ru","available":false,"reason":"image_based"}]}
        """.data(using: .utf8)!
        let info = try JSONDecoder().decode(PlaybackInfo.self, from: json)
        XCTAssertEqual(info.mode, "remux")
        XCTAssertTrue(info.streamUrl.contains("token=orb_x"))
        XCTAssertEqual(info.audioTracks.first?.channels, 6)
        XCTAssertEqual(info.subtitleTracks.filter { $0.available }.count, 1)
    }

    func testAppleCapabilityProfile() {
        XCTAssertEqual(Capabilities.appleTV.subtitleDelivery, "hls")
        XCTAssertTrue(Capabilities.appleTV.videoCodecs.contains("hevc"))
        XCTAssertEqual(Capabilities.appleTV.maxAudioChannels, 6)
    }
}
```

## Milestones beyond this plan (planned after the M1 gate)

- **M2 auth:** pairing UI (on-screen code + poll), Keychain persistence, profile picker (server-side `activeProfileId`), device visible/revocable in web Settings.
- **M3 the app:** home rails (`.focusSection()` per row), title/season/episode pages, search, continue-watching resume, progress reporting (10s + pause/exit), next-episode autoplay, kids profiles verified end-to-end.
- **M4 polish:** Top Shelf (continue watching), info-panel metadata, EN/RU String Catalogs, optional I-frame trick-play.

These are deliberately deferred: M1 is a go/no-go gate whose result (AVPlayer-only vs VLCKit) reshapes M3's player layer, and it benefits from the user's real hardware + the parked hardware/account decisions.
